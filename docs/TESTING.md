# Automated Testing & Verification Guide: StudyMate

## 1. Testing Philosophy & Strategy

StudyMate incorporates a rigorous, automated testing strategy to guarantee that core business logic, authentication workflows, file ingestion security, and database reporting perform reliably and securely.

The test suite is built on **JUnit 5 (Jupiter)** and **Mockito 5.11**, running natively under **Java 21 LTS** via the Maven Surefire plugin.

---

## 2. Test Suite Breakdown (25 Automated Tests)

The test suite comprises 25 unit and integration tests across 5 targeted test suites located in `src/test/java/com/studymate/`:

```
src/test/java/com/studymate/
├── util/
│   └── SecurityUtilTest.java          [4 Tests]  --> Cryptographic primitives & XSS sanitization
├── service/
│   ├── AcademicServiceTest.java       [3 Tests]  --> Course & Subject curriculum rules
│   ├── AuthServiceTest.java           [12 Tests] --> Registration, Verification, Login, Password Reset
│   └── ResourceServiceTest.java       [5 Tests]  --> Upload validation, MIME checking, Path Traversal
└── dao/
    └── JdbcReportingDaoTest.java      [1 Test]   --> Direct JDBC multi-join statistical queries
```

### Detailed Suite Inventory

#### 1. `SecurityUtilTest` (4 Tests)
- `testHashPasswordAndVerify()`: Asserts that BCrypt creates valid non-reversible hashes that verify against correct plaintext passwords.
- `testGenerateSecureToken()`: Verifies that 32-byte tokens generated by CSPRNG have correct length and entropy.
- `testHashTokenDeterministic()`: Confirms that SHA-256 token hashing produces consistent 64-character hex digests for database lookups.
- `testEscapeHtml()`: Validates that potentially malicious XSS payloads (`<script>`, `"`, `'`, `&`) are sanitized into safe HTML entities.

#### 2. `AcademicServiceTest` (3 Tests)
- `testCreateCourse_Success()`: Verifies successful persistence of a valid course entity.
- `testCreateCourse_BlankCode_ThrowsException()`: Confirms rejection of courses with empty/whitespace codes.
- `testCreateCourse_DuplicateCode_ThrowsException()`: Asserts validation exception when attempting to register an existing course code.

#### 3. `AuthServiceTest` (12 Tests)
- `testRegisterStudent_Success()`: Asserts complete student registration with automatic `ROLE_STUDENT` assignment and verification token generation.
- `testRegisterStudent_MissingName_ThrowsException()`: Validates mandatory full name constraint.
- `testRegisterStudent_InvalidEmail_ThrowsException()`: Rejects malformed email structures.
- `testRegisterStudent_PasswordMismatch_ThrowsException()`: Rejects non-matching password confirmation.
- `testRegisterStudent_TermsNotAccepted_ThrowsException()`: Enforces terms and conditions acceptance.
- `testRegisterStudent_DuplicateEmail_ThrowsException()`: Prevents duplicate account creation.
- `testVerifyEmail_Success()`: Asserts successful account activation on valid verification token.
- `testVerifyEmail_ExpiredToken_ThrowsException()`: Rejects expired email verification tokens.
- `testAuthenticate_Success()`: Verifies valid login, password match, and `UserSessionDto` generation.
- `testAuthenticate_WrongPassword_ThrowsException()`: Rejects invalid credentials.
- `testAuthenticate_DisabledAccount_ThrowsException()`: Blocks deactivated or suspended accounts.
- `testResetPassword_Success()`: Asserts valid password update and token invalidation.

#### 4. `ResourceServiceTest` (5 Tests)
- `testCreateResource_MissingTitle_ThrowsException()`: Asserts mandatory title validation.
- `testCreateResource_ExternalLinkSuccess()`: Validates registration of external educational links.
- `testCreateResource_PdfSuccess()`: Validates successful multipart PDF ingestion and `ResourceFile` linkage.
- `testCreateResource_PathTraversalSanitized()`: Verifies that malicious paths (`../../etc/passwd.pdf`) are sanitized into safe local filenames.
- `testFindById_NotFound()`: Returns clean empty Optional when resource does not exist.

#### 5. `JdbcReportingDaoTest` (1 Test)
- `testGetPlatformOverviewStatistics()`: Executes direct multi-table SQL query against HikariCP datasource and asserts non-null statistical aggregations.
